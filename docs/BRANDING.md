# Branding — Atomic Dream Engine

## Name

- Full name: **Atomic Dream Engine**
- Acceptable short form: **ADE** (internal/shorthand contexts)
- Former name (legacy docs/history): "Atomic AI Studio" — do not use for
  new material.

## Usage guidance

- Write it as "Atomic Dream Engine", not "atomic dream engine" or
  "AtomicDreamEngine" in prose.
- The bundle identifier `com.atomicdream.engine` and executable name
  `atomic-dream-engine.exe` are technical identifiers — keep them as-is.
- The user data directory `%LOCALAPPDATA%\AtomicAIStudio` is a legacy
  compatibility path retained to preserve existing installs — it is not
  part of the public brand.

## Logo / icon

- Source of truth: `apps/desktop/src-tauri/icons/` and the frontend logo
  asset (`apps/desktop` — `logo-*.png` in built assets).
- Original works created for this project; may be used to refer to the
  project (attribution, articles, package managers).
- Don't modify the logo or use it in ways that imply endorsement of an
  unrelated product.

## Third-party marks

NVIDIA, CUDA, FFmpeg, Tauri, React, ComfyUI, Stable Diffusion, Wan and
other model/runtime names belong to their owners. Refer to them
nominatively only (compatibility/descriptive use).
